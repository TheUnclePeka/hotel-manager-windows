Предварительная версия 0.2.0. Реализованы аккаунты и роли, приглашения QR/JSON, отдельные защищённые профили, ротация сессий и ограничение офлайн-доступа до 24 часов. Это проверочная сборка, не готовый публичный выпуск.

Исходные данные, история частного проекта, сертификаты и ключи не импортированы. Использование общей модели и интерфейса фиксируется локальными пакетами в vendor/.

## Разработка

Node.js 24+, Windows x64.

```sh
npm ci
npm run build
npm run dist
```

`build` генерирует нейтральные значки, собирает main/preload и копирует интерфейс из установленного пакета. `dist` создаёт NSIS-установщик в `release/`. После установки зависимостей с `--ignore-scripts` отдельно выполните `node node_modules/electron/install.js`.

У приложения новый идентификатор и отдельный каталог профиля `HotelManager`. Частный адрес сервера и его сертификат в сборке отсутствуют. Для публичного сертификата используется системное доверие. Для локального сервера можно подтвердить профиль connection.json или приглашение с SHA-256 сертификата; проверяются отпечаток, имя сервера и срок сертификата.

Установщик не подписан доверенным издателем. Непроверенная автоматическая установка EXE отключена и в интерфейсе, и в нативном IPC. Защищённое хранилище Windows отказывает при ошибке чтения, вместо создания нового ключа поверх старого. Перед выпуском нужны проверка чистой установки и сценариев TLS/профилей в настоящем Electron.

`npm test` проверяет привязку сертификата. `THIRD_PARTY_NOTICES.txt` содержит собранный перечень лицензий npm-зависимостей; перед выпуском требуется окончательная проверка состава.
